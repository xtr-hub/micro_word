# 微单词 - 英语单词学习应用

一个简洁、高效的英语单词学习应用，帮助用户轻松掌握英语单词。

## 功能特点

- 📚 单词学习：通过选择正确的释义来学习单词
- 🔊 发音功能：点击发音按钮听单词发音
- 📝 例句展示：每个单词配有例句，帮助理解单词用法
- ⭐ 收藏功能：收藏重要单词，方便后续复习
- 📊 学习进度：显示当前学习进度

## 技术栈

- Flutter：跨平台移动应用开发框架
- Dart：编程语言
- 本地存储：使用 shared_preferences 存储单词和学习进度

## 项目结构

```
lib/
├── models/         # 数据模型
├── pages/          # 页面
├── storage/        # 存储相关
├── main.dart       # 应用入口
└── routes.dart     # 路由配置
```

## 运行项目

1. 克隆项目到本地
2. 安装依赖：`flutter pub get`
3. 运行项目：`flutter run`

## 开发环境

- Flutter SDK：3.0.0+
- Dart SDK：2.17.0+
- Android Studio / VS Code
