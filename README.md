# 微单词

一个简单易用的单词学习应用，基于Flutter开发。

## 功能特点

- 单词学习和记忆
- 学习进度跟踪
- 测试功能
- 单词本管理
- 语音发音

## 技术栈

- Flutter
- Dart
- 本地存储
- 图表库

## 快速开始

### 环境要求

- Flutter SDK 3.11.0+
- Dart SDK 3.1.0+

### 安装依赖

```bash
flutter pub get
```

### 运行应用

```bash
flutter run
```

## 构建应用

### Android

```bash
flutter build apk
```

### iOS

```bash
flutter build ios
```

### Web

```bash
flutter build web
```

## 项目结构

```
lib/
├── models/          # 数据模型
├── pages/           # 页面组件
└── main.dart        # 应用入口
```
